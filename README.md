# Genezis-AI 🌍

A living AI virtual world.

## Concept

Genezis-AI starts with a single digital being that has needs, goals and the ability to learn.

The being can:

- work
- earn money
- buy resources
- develop skills
- interact with others
- help build a growing community

## Vision

The goal is to create a browser-based world where users can interact with the simulation through an AI command interface.

Examples:

- "Build a house"
- "Create a forest"
- "Give this character a new skill"
- "Explain why this citizen is unhappy"
